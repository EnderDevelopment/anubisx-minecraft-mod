# AnubisX

AnubisX is a comprehensive Minecraft mod designed to enhance your gameplay experience with a wide range of features. This mod is built for Fabric Loader and offers various functionalities such as Anchor Aura, Anchor Macro, Animated Notifications, Armor Durability HUD, Assisted Placement, Auction Price Tracker, Auto Builder, Auto City, Auto Eat, Auto Reconnect, Auto Replenish, Auto Tool, Auto Totem, Block ESP, Block Entity Debug, Block Notifier, Block Overlay Themes, Buy Sell Comparison, Character Models 3D, Chunk Overlays, Click GUI, Crystal Aura, Crystal Optimizer, Custom Crosshair, Custom Fonts Themes, Custom Hand Poses, Custom Sky Themes, Elytra Fly, Elytra Swap, Exportable Price Data, FPS Ping Coordinates, Farm Profit Calculator, First Person Hands 3D, Floating Relics, Fly, Free Look, Freecam, Friend Guard, Ghost Block Previews, Glow Effects, Inventory Organization, Inventory Valuation, Item Cooldown HUD, Jump Reset Key Throw, Layer by Layer Building, Low Health Warning, Material Calculator, Material Cost Estimator, Missing Block Counter, Module Settings Keybinds, Netherite Finder, No Jump Delay, No Render Options, Orange Chest Tracers, Particle Effects, Player Tracers, Price Alerts, Price History Database, Prime Chunk Finder, Profiles Configurations, Profit Margin Calculator, Progress Tracker, Projectile Trajectory Previews, Rotation Mirroring, Schematic Loader, Spear Swap, Speed, Spotify Controls, Storage ESP, Sus Chunk Finder, Swing Animation Styles, Target Info HUD, Totem Effects, Trading Ledger, Waypoints, Weather Notifications, Xray Visualization, and Zoom.

## Installation

1. Install Fabric Loader for Minecraft 1.21.1.
2. Download the AnubisX mod jar file.
3. Place the mod jar file in the `mods` folder of your Minecraft directory.

## Use

1. Launch Minecraft with Fabric Loader.
2. The mod will be automatically loaded.
3. Access the mod features through the in-game interface or keybindings.

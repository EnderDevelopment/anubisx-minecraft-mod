# AnubisX

AnubisX is a comprehensive Minecraft mod designed to enhance gameplay with a wide range of features. It includes modules for automation, visualization, utility, and more, making it a versatile tool for players of all levels. Keywords: Minecraft, mod, automation, visualization, utility, Fabric.

## Installation

1. Install Fabric Loader for Minecraft 1.21.1.
2. Download the AnubisX mod jar file from the [GitHub repository](https://github.com/enderdevelopment/mod).
3. Place the downloaded jar file in the `mods` folder of your Minecraft installation directory.

## Usage

1. Launch Minecraft with the Fabric Loader installed.
2. Open the game and press the Right Shift key to open the Click GUI.
3. Navigate through the various categories and enable or disable modules as desired.
4. Configure module settings and keybinds using the Click GUI.
